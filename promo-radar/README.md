# 優惠雷達 Promo Radar

專門幫你蒐集「花時間可換到的優惠／回饋／哩程情報」的小工具，並加上銀行 App 提醒、小樹點換機票進度與一週自動摘要。

## 功能

- 自動抓取 PTT：`creditcard`、`Lifeismoney`、`Points`
- 依你的偏好（預設：CUBE、網購、高鐵、小樹點、哩程、日本）做相關分數排序
- **銀行 App 活動提醒**：每日切權益、領券、全額扣繳、點數效期等可勾選完成
- **小樹點 → 機票進度**：設定目前點數、回饋率與目標航線，估算還差多少點／約需消費
- **一週自動摘要**：依情報、提醒與小樹點進度產生當週行動清單（同週會快取，可手動重產）
- 搜尋、依版面篩選、調整最低相關分
- 偏好設定存在 `data/profile.json`

## 啟動

```bash
cd promo-radar
python3 -m pip install -r requirements.txt
python3 -m uvicorn backend.main:app --host 0.0.0.0 --port 8787
```

瀏覽器開啟：http://127.0.0.1:8787

## 建議用法

1. 先打開「偏好設定」，確認卡片與興趣
2. 在上方三個面板：
   - 勾完今天的銀行 App 提醒
   - 填入目前小樹點，選好目標航線（例如台北⇄東京）
   - 看一週摘要的行動建議
3. 按「重新抓取」更新 PTT 情報
4. 把「最低相關分」設在 20+ 或 40+，先看高相關
5. 點標題開 PTT 原文，再回銀行 App 登錄活動

## API 速覽

| 路徑 | 說明 |
|------|------|
| `GET /api/deals` | 情報列表 |
| `GET /api/reminders` | 銀行 App 提醒看板 |
| `POST /api/reminders/complete` | 標記提醒完成／取消 |
| `GET /api/tracker` | 小樹點機票進度 |
| `PUT /api/tracker` | 更新點數／航線／回饋率 |
| `GET /api/summary/weekly` | 一週摘要（`force=true` 強制重算） |
| `GET /api/dashboard` | 一次取得提醒＋進度＋摘要 |

## 注意

- 本工具只做公開資訊彙整與規劃估算，不保證活動仍有效
- 小樹點轉哩程比例、稅金與酬賓機位以官方為準
- 實際權益與回饋以銀行／官網為準
- 請勿為了回饋購買不需要的東西；帳單請全額繳清
